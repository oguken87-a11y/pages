AI動画編集 環境構築マニュアル（Mac版）

対象者：動画編集を行うMacの利用者の方（Googleアカウントもご本人のもの）
対応OS：macOS（Apple シリコン・Intel のどちらも可） ／ 所要時間：約40〜60分
配布物：douga-henshu.zip（動画編集キット）、編集の参考チャンネル集_スクショ.pdf（お手本選びの参考資料。zipにも同じものが入っています）

1. 概要

目的

お手本にしたいYouTube動画の編集をAIが分析し、同じ作り方で手元の動画を編集できる環境を、Macに整えます。

構築後にできること

  • お手本のYouTube動画を1本指定すると、AIが編集の特徴を分析し、「編集レシピ」（カット割り・テロップの大きさや色・効果音などの仕様書）にまとめます。
  • 撮影した動画を渡すと、AIが編集レシピに沿って編集します。編集ソフトを操作する必要はありません。修正は「00:42のテロップを大きく」のように文章で指示します。
  • 最初に冒頭3分を仕上げて確認を求めるので、問題がなければ全体を同じ仕様で編集します。

役割分担

分析Gemini
Googleの生成AI

お手本の動画を見て、カットの切り替わる時刻、テロップの文言・大きさ・色などを書き出す

編集Codex
OpenAIのAIエージェント。文章の指示を受けて、Mac上でファイル操作やコマンドの実行を行う

Geminiの分析結果をもとに編集レシピを作り、撮影した動画を編集する

確認・判断利用者

お手本の選定、素材の受け渡し、仕上がりの確認と修正の指示

本マニュアルで行う作業（初回のみ）

  1. Gemini を使うためのAPIキーを発行し、Macに保存する
  2. 編集に必要なソフト（Homebrew・Python・FFmpeg）を入れる
  3. 試運転で、分析が動くことを確かめる

作業の大半は、Codex が手順を案内し、コマンドの実行も行います。利用者が行うのは、APIキーの発行と保存、Homebrew のインストール（Macのパスワード入力が必要なため）、Codex からの実行許可の確認です。
構築が終われば、以降は「お手本のURL」と「撮影した動画」を渡すだけで編集を依頼できます。

費用

  • Gemini：無料枠で利用を始められます（1日・1分あたりの利用回数に上限があります）。
  • Codex：契約中のプランの範囲で利用します。

3. 注意事項

APIキーはパスワードと同じ扱いです。

  • LINE・メール・チャット・AIへのメッセージに貼り付けない
  • 人に見せない・スクリーンショットに写さない
  • キーは③でMacに保存すれば、AIはそこから読み取ります。AIにキーを伝える必要はありません。
  • 第三者に見られた可能性がある場合は、キーを削除して再発行してください（キーの削除・再発行）。
  • 無料枠には利用回数の上限があります。また、無料枠で送信したデータは、Googleがサービス改善に利用する場合があるとされています。長い動画を多く分析するようになった段階で、有料プラン（課金）の設定を検討してください。本マニュアルでは課金の設定は行いません。
  • 分析できるYouTube動画は「公開」のものだけです（限定公開・非公開は不可）。
  • Codex は、インストールや外部との通信の前に実行の許可を求めることがあります。内容を確認して許可してください。

1動画編集キットを配置する

  1. 受け取った douga-henshu.zip をダウンロードする（通常は「ダウンロード」フォルダーに保存されます）。
  2. Finder で douga-henshu.zip をダブルクリックして展開する（Safari の設定によっては、ダウンロード時に自動で展開されます）。
  3. Finder のメニュー「移動」→「ホーム」（command + shift + H）でホームフォルダーを開き、展開してできた douga-henshu フォルダーをそこへ移動する。
  4. douga-henshu の中に README.md・gemini_video.py などがあることを確かめる。
  • douga-henshu の中にさらに douga-henshu がある場合は、内側のフォルダーをホームフォルダーに移動してください。
  • フォルダー名は半角英字のまま変えないでください（AIが使う道具が正しく開けなくなることがあります）。

2APIキーを発行する

  1. ブラウザ（Safari・Chrome など）で次のページを開く：
    https://aistudio.google.com/apikey
  2. ご自身のGoogleアカウントでログインする（別のアカウントでログインしている場合は、右上のアイコンから切り替える）。
  3. 初回は利用規約への同意画面が表示されます。内容を確認して同意する。
  4. 「APIキーを作成」（英語表示の場合は「Create API key」）を押す。
  5. プロジェクト（キーを管理する単位）の選択画面が表示された場合は、既存のものを選ぶか、「新しいプロジェクトで作成」（「Create API key in new project」）を選ぶ。キーに名前を付けられる場合は「動画解析用」とする。
  6. 英数字の長い文字列（多くは「AIza」で始まります）が表示されます。これがAPIキーです。横の「コピー」ボタンでコピーする。この画面はまだ閉じない。

ボタンの名称や配置は、Googleの更新で変わることがあります。「API キー」「Get API key」「Create」などの表記を探してください。

3APIキーをMacに保存する

  1. ターミナルを開く（Finder の「アプリケーション」→「ユーティリティ」→「ターミナル」、または command + space で「ターミナル」と入力）。
  2. 次の1行を貼り付けて return キーを押す。
read -rs "k?APIキーを貼り付けて return（画面には表示されません）: "; ( umask 077; printf '%s' "$k" > ~/.gemini_api_key ); unset k; echo; echo "保存しました（$(wc -c < ~/.gemini_api_key | tr -d ' ')文字）"
  1. 「APIキーを貼り付けて return」と表示されたら、②でコピーしたキーを command + V で貼り付けて return キーを押す（貼り付けても画面には何も表示されませんが、入力されています）。
  2. 「保存しました（39文字）」のように表示されれば完了です（文字数はキーによって多少異なります）。
  • キーはホームフォルダーの .gemini_api_key というファイルに、本人だけが読める設定で保存されます（名前が「.」で始まるファイルは、Finder では通常表示されません）。
  • 「not a valid identifier」と表示される場合は、ターミナルが古い形式（bash）で動いています。zsh と入力して return キーを押してから、もう一度貼り付けてください。
  • 文字数が 0 や極端に少ない場合は、貼り付けに失敗しています。もう一度この手順を行ってください（上書きされます）。
  • ②のブラウザの画面は閉じてかまいません。キーはいつでも https://aistudio.google.com/apikey で確認できます。

4Homebrew を入れる

すでに Homebrew が入っている場合（ターミナルで brew --version と入力して番号が表示される場合）は、この手順は不要です。

  1. ターミナルに次の1行を貼り付けて return キーを押す（Homebrew 公式のインストール用コマンドです）。
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
  1. 「Password:」と表示されたら、Macにログインするときのパスワードを入力して return キーを押す（入力しても画面には表示されません）。
  2. 「Press RETURN/ENTER to continue」と表示されたら return キーを押す。
  3. 完了まで5〜15分ほどかかります（初めての場合は、開発用の部品「コマンドライン・デベロッパ・ツール」も自動で入ります）。「Installation successful!」と表示されれば終了です。
  4. 続けて次の1行を貼り付けて return キーを押す（ターミナルから brew が使えるように設定します）。
if [ -x /opt/homebrew/bin/brew ]; then echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile; eval "$(/opt/homebrew/bin/brew shellenv)"; fi; brew --version

Homebrew 4. で始まる番号が表示されれば完了です。

  • 「command not found: brew」と表示される場合は、ターミナルを一度終了して開き直し、brew --version を入力してください。
  • Macのパスワードは Codex には入力できないため、この手順はご自身で行ってください。

5APIキーの接続を確認する（Codex が実行）

if [ ! -s ~/.gemini_api_key ]; then echo "NO KEY"; else r=$(curl -s -H "x-goog-api-key: $(cat ~/.gemini_api_key)" "https://generativelanguage.googleapis.com/v1beta/models?pageSize=1000"); if echo "$r" | grep -q 'models/gemini-3.8-flash'; then echo "OK: gemini-3.8-flash"; else echo "$r" | head -8; fi; fi

OK: gemini-3.8-flash と表示されれば成功です（キーの値は表示されません）。

「NO KEY」③が完了していない。③をやり直す
「API key not valid」（code 400）キーの貼り付け誤り。②のページでキーをコピーし直し、③をやり直す
code 403プロジェクトで Gemini が使えない状態。②で、新しいプロジェクトでキーを作り直す
一覧は表示されるが OK が出ないキーは有効だが、指定のモデルが見つからない。動画編集の依頼元に連絡する

6Python と FFmpeg を入れる（Codex が実行）

brew install python ffmpeg

完了後、次の2行でバージョンを確認する。

python3 --version
ffmpeg -version

Python 3.10 以上の番号と、ffmpeg version で始まる行が表示されれば完了です。

「command not found: brew」先に eval "$(/opt/homebrew/bin/brew shellenv)" を実行する
python3 --version が 3.9 以下Mac に元から入っている Python が使われている。eval "$(/opt/homebrew/bin/brew shellenv)" を実行してから確認し直す

7Python の部品を入れる（Codex が実行）

キット専用の仮想環境（.venv）を作り、分析に必要な部品（numpy・pillow・yt-dlp）を入れます。

cd ~/douga-henshu && python3 -m venv .venv && .venv/bin/pip install numpy pillow yt-dlp

最後に Successfully installed … と表示されれば完了です。以降、キットのプログラムは .venv/bin/python で実行します。

8試運転（動画の冒頭30秒を分析・Codex が実行）

  1. 任意のYouTubeの公開動画のURLを1本用意する（例：https://www.youtube.com/watch?v=xxxxxxxxxxx）。
  2. 次の2行を順に実行する。ここにURL を用意したURLに置き換える（前後の " は残す）。
cd ~/douga-henshu
.venv/bin/python gemini_video.py "ここにURL" test_prompt.md test_out.md --start 0 --end 30 --fps 1
  1. 1〜3分ほどで saved test_out.md chars … と表示されます。
  2. douga-henshu/test_out.md に、カットの時刻とテロップの表が書かれていれば成功です。
「HTTP 400」URLの誤り、または限定公開・非公開の動画。別の公開動画で試す
「HTTP 403」⑤に戻って確認する
「HTTP 429」無料枠の利用回数の上限。時間をおいて（1分〜翌日）やり直す
「GEMINI_API_KEY が見つかりません」③をやり直す
「No module named …」⑦をやり直す

9お手本の分析と編集を依頼する

  1. お手本の動画を1本選ぶ。douga-henshu/参考チャンネル集.md（11チャンネル。画面の例は同じフォルダーの 編集の参考チャンネル集_スクショ.pdf）から、ご自身の動画の形式（1人で話す／2人の対談／図やスライドでの解説）に近いものを選び、YouTubeでURLをコピーする。
  2. Codex で douga-henshu フォルダーを開いた状態で、AIへの頼み方.md の枠内の文を貼り付け、「お手本のURL：」のあとに1のURLを入れて送信する。
  3. Codex がお手本を分析し、編集レシピ.md を作成します。その後、編集したい動画の保存場所を Codex に伝えると、冒頭3分の編集から始まります。

以上で構築は完了です。

完了後の連絡

  • 動画編集の依頼元には「⑧の試運転まで完了した」ことだけを伝えてください。キーそのものは伝えないでください。
  • 途中で止まった場合は、①〜⑨のどこで止まったかと、表示された文言（キーが写っていないもの）を伝えてください。

キーの削除・再発行

  1. https://aistudio.google.com/apikey を開く。
  2. 一覧の該当のキーの横にある「削除」（ごみ箱のマーク）を押す。
  3. 新しいキーを発行したら、③の手順をもう一度行う（古いキーは上書きされます）。⑤で接続を確認する。
  4. Mac からキーを消すだけの場合は、ターミナルで次の1行を実行する。
rm ~/.gemini_api_key
