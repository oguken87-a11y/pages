手順書

Gemini APIキーの取得から、AIで動画編集ができるまで

この手順書を使う人：動画編集をするPCの持ち主の方（Googleアカウントもその方のもの）
PC：Windows ／ 所要時間：40分くらい
いっしょに受け取るもの：douga-henshu.zip（動画編集キット）

全体像（まずここを読む）

ひとことで言うと

「この動画みたいに編集して」と、AIに頼めるようにするための準備です。

どんなことができるようになるか

  • 好きなYouTubeの動画を1本「お手本」に選び、自分で撮った動画を渡すと、AIがお手本と同じような字幕・効果音・場面の切り替え方で編集してくれます。
  • 編集ソフトを自分で触る必要はありません。AIに文章で頼み、出来上がりを見て「ここをこう直して」と言うだけです。
  • まず最初の3分だけ作って見せてくれるので、それを見てOKなら、残りも同じように仕上げてくれます。

今回やること（最初の1回だけ・40分くらい）

  1. Geminiを使うための「合い言葉（APIキー）」を作って、PCに覚えさせる
  2. 編集に使う道具をPCに入れる
  3. ためしに動かしてみる

ほとんどの作業は、Codexが1つずつ案内して、自分でやってくれます。あなたがするのは、Codexの案内どおりに画面のボタンを押すことと、Codexの「これをしていいですか」に「はい」と答えることです。
準備が終われば、次からは「お手本のURL」と「撮った動画」を渡すだけで編集を頼めます。

お金

  • Gemini：無料で始められます（1日に使える回数に上限があります）。
  • Codex：いま入っているCodexのプランの範囲で使います。

ことばの説明

APIキーGeminiを、あなたのGoogleアカウントで使うための合い言葉。英数字の長い文字列。パスワードと同じで、人に教えない
環境変数PCの中にある「メモ欄」のようなもの。ここにAPIキーを書いておくと、AIが自分で読み取れる
Codex文章で頼むと、PCの操作や作業をしてくれるAIのアプリ
PowerShell文字でPCに命令する画面。言われた1行を貼り付けて Enter を押すだけでよい
Python・FFmpeg編集の道具を動かすためのソフト。入れておくだけで、自分で使うことはない
zipいくつかのファイルを1つにまとめたもの。右クリック→「すべて展開」で元に戻る
テロップ動画の中に出る字幕や文字
お手本「この動画みたいにしたい」と真似する元のYouTube動画

先に知っておくこと（大事）

APIキーは、パスワードと同じ扱いです。

  • LINE・メール・チャット・AIへのメッセージに貼らない
  • 人に見せない・スクリーンショットに写さない
  • キーはPCに覚えさせれば、AIはそこから自分で読みます。AIに「キーはこれです」と教える必要はありません。
  • 万一ほかの人に見られたら、キーを消して作り直してください（いちばん下）。
  • 無料のまま使えますが、無料枠には1日・1分あたりに使える回数の上限があります。また、無料枠で送ったデータはGoogleがサービスの改善に使うことがあるとされています。長い動画をたくさん解析するようになったら、支払い（課金）の設定をするかどうかを決めてください。この手順書では課金の設定はしません。
  • 解析できるYouTube動画は「公開」のものだけです（限定公開・非公開は不可）。

1APIキーを作る

  1. 動画編集をするPCで、ブラウザ（Chromeなど）を開く。
  2. 次のページを開く：https://aistudio.google.com/apikey
  3. あなたのGoogleアカウントでログインする（別のアカウントでログインしていたら、右上のアイコンから切り替える）。
  4. 初めてのときは、利用規約に同意する画面が出ます。読んで、同意して進む。
  5. 「APIキーを作成」（英語の画面なら「Create API key」）を押す。
  6. 「プロジェクト」（キーを入れておく箱のようなもの）を選ぶ画面が出たら、すでにあればそれを選び、無ければ「新しいプロジェクトで作成」（「Create API key in new project」）を選ぶ。キーに名前を付けられる場合は「動画解析用」とする。
  7. 英数字の長い文字列（「AIza」で始まることが多い）が出ます。これがAPIキーです。横の「コピー」ボタンでコピーする。この画面はまだ閉じない。

ボタンの名前や位置は、Googleの更新で少し変わることがあります。「API キー」「Get API key」「Create」などの言葉を探してください。

2PCにキーを覚えさせる

  1. 画面左下のスタート（Windowsマーク）を押し、「環境変数」と入力する。
  2. 「環境変数を編集」（「アカウントの環境変数を編集」）を開く。「システム環境変数の編集」ではなく、アカウントの方。
  3. 上半分の「（あなたの名前）のユーザー環境変数」の下にある「新規」を押す。
  4. 次のとおり入れて「OK」。
    変数名GEMINI_API_KEY（半角・大文字。この通りに）
    変数値①でコピーしたキーを貼り付ける（前後に空白を入れない）
  5. 一覧に GEMINI_API_KEY が増えたのを見てから、もう一度「OK」で閉じる。
  6. 開いていた Codex・Claude Code・PowerShell を全部閉じる。（開き直さないと、新しく入れたキーが見えません）

①のブラウザの画面は閉じてかまいません。キーはいつでも https://aistudio.google.com/apikey で見直せます。

3キーがつながるか確かめる

スタートから「PowerShell」を開き、次の1行を貼り付けて Enter（キーは画面に出ません）。

if (-not $env:GEMINI_API_KEY) { "NO KEY" } else { (Invoke-RestMethod -Uri "https://generativelanguage.googleapis.com/v1beta/models" -Headers @{ "x-goog-api-key" = $env:GEMINI_API_KEY }).models.name | Select-String "gemini-3.8-flash" }

models/gemini-3.8-flash を含む行が出れば成功。

「NO KEY」②のあとPowerShellを開き直していないか、変数名がちがう。
「(400)」「API key not valid」キーの貼り付けまちがい。②の変数値を入れ直す。
「(403)」プロジェクトでGeminiが使えない状態。①で、新しいプロジェクトでキーを作り直す。
何も出ずエラーも無いキーは通っているが、そのAIが見つからない。動画編集を頼む人にそう伝える。

4Python を入れる

PowerShellで次の1行。途中で「同意しますか」と聞かれたら Y → Enter。「このアプリがデバイスに変更を加えることを許可しますか」と出たら「はい」。

winget install --id Python.Python.3.13 -e

終わったらPowerShellを閉じて開き直し、次を入れる。

py --version

Python 3. で始まる番号が出れば成功。

「winget が見つからない」Microsoft Store で「アプリ インストーラー」を入れる（または更新する）。
「py が見つからない」PowerShellを閉じて開き直す。それでもだめならPCを再起動する。
python でStoreが開くこの手順では py を使うので気にしなくて大丈夫。

すでにPython 3.10以上が入っていれば、この④は飛ばしてかまいません（py --version で確かめる）。

5FFmpeg を入れる

動画・音声を切ったりつないだりする道具です。PowerShellで次の1行。途中で聞かれたら Y → Enter。

winget install --id Gyan.FFmpeg -e

終わったらPowerShellを閉じて開き直し、次を入れる。

ffmpeg -version

ffmpeg version で始まる行が出れば成功。

6Python の部品を入れる

PowerShellで次の1行。

py -m pip install numpy pillow yt-dlp

最後に Successfully installed … と出れば成功（「Requirement already satisfied」でも大丈夫）。

7動画編集キットを置く

  1. 受け取った douga-henshu.zip を右クリック →「すべて展開」。
  2. 展開先に C:\ と入れて「展開」。
  3. C:\douga-henshu の中に、README.md・gemini_video.py などがあるのを見る。
    • C:\douga-henshu\douga-henshu\ のように二重になっていたら、中の方の douga-henshu フォルダーを C:\ に移す。

フォルダーの名前は半角英字のままにしてください（日本語の名前にすると、AIの道具がうまく開けないことがあります）。

8試運転（動画の最初の30秒を解析）

  1. 好きなYouTubeの公開動画を1本選び、URLをコピーする（例：https://www.youtube.com/watch?v=xxxxxxxxxxx）。
  2. PowerShellで、次の2行を順に入れる。2行目の ここにURL を、コピーしたURLに置き換える（前後の " は残す）。 
    cd C:\douga-henshu
    py gemini_video.py "ここにURL" test_prompt.md test_out.md --start 0 --end 30 --fps 1
  3. 1〜3分ほど待つと、saved test_out.md chars … と出ます。
  4. C:\douga-henshu\test_out.md をメモ帳で開き、カットの時刻とテロップの表が書いてあれば成功です。
「HTTP 400」URLのまちがい、または限定公開・非公開の動画。別の公開動画で試す。
「HTTP 403」③に戻って確かめる。
「HTTP 429」無料枠の回数の上限。しばらく（1分〜翌日）待ってからやり直す。
「GEMINI_API_KEY が見つかりません」②をやり直し、PowerShellを開き直す。
「No module named …」⑥をやり直す。

9AIに編集を頼む

  1. お手本の動画を1本選ぶ。C:\douga-henshu\参考チャンネル集.md（11チャンネル。画面のスクショは同じフォルダーの 編集の参考チャンネル集_スクショ.pdf）から、自分の動画の形に近いもの（1人で話す／2人の対談／図やスライドで説明）を選び、YouTubeで開いてURLをコピーする。
  2. Codex（または Claude Code）を開き、作業フォルダーに C:\douga-henshu を選ぶ。
  3. C:\douga-henshu\AIへの頼み方.md を開き、枠の中の文をそのまま貼る。「お手本のURL：」のあとに、1で選んだ動画のURLを入れて送る。
  4. AIがお手本を解析して「編集レシピ.md」を作ります。そのあと、編集したい素材（撮った動画）のある場所をAIに伝えると、冒頭3分の編集から始まります。

ここまでできれば完了です。

終わったら

  • 動画編集を頼む人には「⑧の試運転まで終わった」とだけ伝える。キーそのものは伝えない。
  • 止まったときは、①〜⑨のどこで止まったかと、出たエラーの文字（キーが写っていないもの）を伝える。

キーを消す・作り直すとき

  1. https://aistudio.google.com/apikey を開く。
  2. 一覧の該当のキーの横にある「削除」（ごみ箱のマーク）を押す。
  3. 新しく作り直したら、②の変数値を新しいキーに入れ替え、③で確かめる。
