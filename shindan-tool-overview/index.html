3. 全設問と所属する観点

  1. オープニング／場の設計
    冒頭で「この時間はあなたのための時間です」と、プロとして言い切っている
  2. オープニング／場の設計
    終了時刻を「余裕を持って何時まで大丈夫か」の形で先に確認している
  3. ヒアリング
    相手の最初の答えで止めず、「他にはありますか」「なぜですか」で本音まで降りている
  4. ヒアリング
    気持ちや状態を10点満点などの数値で答えてもらい、満点に届かない差分を掘り下げている
  5. ヒアリング
    自分の商品で必ず確認すべき項目を事前に決めていて、聞き漏らしが起きない
  6. 価値観教育
    ノウハウを詳しく教えるのではなく、相手が「できそう」と感じる状態を作ることを目的にしている
  7. 価値観教育
    相手が既に経験している別の領域（スポーツ・料理・仕事など）に喩え、相手自身に答えを言ってもらっている
  8. 価値観教育
    「あなたには無理」「独学では不可能」とは言わず、うまくいかなかった第三者の具体的な事例で伝えている
  9. 提案・クロージング
    価格を伝えるとき、言い淀まず、他の大きな支出と比べて意味づけができている
  10. 提案・クロージング

4. 4つの観点と重み、観点別スコアの計算

各観点のスコアは 0〜100点です。計算式は、その観点の回答点の合計 ÷（3 × 設問数）× 100 を四捨五入（JavaScript の Math.round）です。

観点 内部ID 重み 設問数 生点の上限
オープニング／場の設計P1_opening2026
ヒアリングP2_hearing3039
価値観教育P3_education3539
提案・クロージングP4_closing1526

総合点（上限100点）は次の式です。

総合点 = Math.round（オープニング×0.20 ＋ ヒアリング×0.30 ＋ 価値観教育×0.35 ＋ 提案・クロージング×0.15）

すべて「いつもできている」なら総合点100点、すべて「できていない」なら0点になります。

6. 最優先の課題とアドバイス

4つの観点のうち、観点別スコアがいちばん低いものを「最優先の課題」として表示します。同点のときは、オープニング／場の設計 → ヒアリング → 価値観教育 → 提案・クロージングの順で先にある方が選ばれます。

選ばれた観点のアドバイスだけが箇条書きで出ます。他の観点のアドバイスは出ません。

オープニング／場の設計

  • 冒頭で相手のための時間だと伝え、安心して相談できる場を作る。
  • 自己紹介は短く、判断に役立つ実績や数字を伝える。
  • 余裕を持って確保できる終了時刻を聞く。
  • 相手の業界になじみのある言葉を使う。

ヒアリング

  • 質問する理由を伝え、許可を取る。
  • 最初の答えから「ほかには」「なぜ」と掘り下げる。
  • 10点満点で聞き、満点との差を確認する。
  • 商品ごとの必須確認項目を一覧にする。
  • 相手の答えを先回りして決めつけない。

価値観教育

  • 相手が「できそう」と感じる状態を目指す。
  • 身近な経験にたとえ、相手自身に答えてもらう。
  • 相づちや表情を見ながら進める。
  • 相手の可能性を否定する言い方を避ける。
  • 第三者の具体的な失敗事例を紹介する。
  • 商品説明に進む前に、聞きたいかを確認する。

提案・クロージング

  • 結果の保証を避け、根拠を持って提案する。
  • 価格は言いよどまずに伝える。
  • 費用の比較対象を示し、何が変わるか伝える。
  • その場で決まらなければ回答期限を具体的に決める。
  • どちらの結論でも相手の判断を尊重する。
